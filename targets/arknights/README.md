# Arknights Profile

This profile targets the retained 2.7.61 (180) capture. Its AnimeStudio assets
adapter can perform a bounded static export from one explicitly selected
Bundle. The separate fixed Kroos regression checks only the eight-file
baseline and is not a general export gate.

`run_static_module.ps1` dispatches target-only phase-one analysis for Unity
object inventory, retained JADX indexing/error correction, current ARM64 ELF
structures, and exact-name cross-layer correlation. Current Android IL2CPP
recovery is deliberately retired because its metadata provenance is not
reproducible; the retained provenance report is audit evidence only. Use the
isolated PC profile for standard metadata v29. Current module input/output
paths are declared in `profile.json`; none of these routes collects data,
starts ADB/Ghidra, or performs runtime observation.

The completed inventory covers all 11,731 retained UnityFS files (11,668
`.ab` plus 63 `.bin`) and records 3,659,173 objects. Java remains partial,
current IL2CPP recovery is blocked by nonstandard metadata and unproven restored
metadata provenance, and Native evidence is structural only. Cross-layer exact
matches are candidates, not proven dependencies or calls.

The profile does not authorize recollection, ADB, Ghidra, runtime work,
injection, or game execution. Its capability and limitation fields are target
facts, not generic Android/Unity/IL2CPP behavior.
